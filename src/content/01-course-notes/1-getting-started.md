# Getting Started

These pages are the running notes from working through React courses, books, and tutorials. Treat them as my own re-explanation of each concept — if I can write the note, I understand the concept.

## How notes are organized

- One topic per file.
- Files are numbered (`1-…`, `2-…`) so they sort in reading order in the editor *and* in the left navigation.
- The first `# heading` in each file is what shows up as the title in the nav and the command palette.

## A quick sanity check

```jsx
function Hello({ name }) {
  return <h1>Hello, {name}!</h1>;
}
```

If that renders without trying, time to revisit JSX fundamentals.
